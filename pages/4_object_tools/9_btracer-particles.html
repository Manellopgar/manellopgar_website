BTracer Particles

The BTracer Particles tool allows you to add particles to each BTracer that you have already created.

  • Particle Radius: Adjust the Particle Radius.
  • Min Radius: Adjust the Minimum Particle Radius.
  • Max Radius: Adjust the Maximum Particle Radius.
  • Seed Rand Radius: Change the seed of the Randomness Radius.
  • Min Rand Offset: Adjust the Minimum Particle Random Position.
  • Max Rand Offset: Adjust the Maximum Particle Random Position.
  • Seed Rand Offset: Adjust the Seed Particle Random Position.
  • Start Color: Set the Start Color for the Particles.
  • End Color: Set the End Color for the Particles.
  • Material: Set the Custom Material for the Particles.
