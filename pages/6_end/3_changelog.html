Changelog

All notable changes to this project are documented below. The most recent release is expanded by default.

📦 v1.5.1 — August 23, 2026
▼

✨Added

  • BMograph Animator: Added "Use Field Selection" menu option. This parameter allows any Field to control the amount of animation for each instance. You can use Basic Fields from any Effector as the Field or Base Field, or combine a Basic Field with other Fields for complex selection controls.
  • BMograph Animator: Added "Field Name" parameter. Defaults to Field_Gradient_Falloff (the common Field for all B4D Tools), but can be changed to use custom Field Attributes. Note: A good use case is when you want to separate a field from the main B4D Tools field or apply it to a specific field only.
  • Modifier_Field_CURVE: Added "Step Gap" parameter (similar to C4D) to quantize the curve falloff into different increments. Works with Effector Step if the "Use with Effector STEP" parameter is enabled.

🐛Fixed

  • Field Formula: Fixed position information for noise, wave, and sine patterns to work consistently with other tools featuring similar functions.
  • BCloner Grid Array: Fixed Random Seed in Random Mode to work as expected.
  • Set Multishader: Fixed "Only Material Slots" parameter to use expected logical numbering.
  • Set Multishader: Fixed "Offset Materials Slots" parameter to use expected logical numbering.
  • Effector Noise Tex: Fixed default scale parameters. Uniform scale is now correctly configured to 0.5 by default.
  • Effector Delay: Fixed the naming of the "Spring" mode.
  • BMoText Object: Fixed glitch when the "Modify Clone" parameter is set to 0%.

⚡Changed

  • Mix Falloff Template: Switched from Mix Shader to Mix Color nodes, as Mix Shader can cause issues with certain material setups.
📦 v1.5.1 — July 14, 2026
▼
⚠️
Recommendation:

While v1.5.0 was updated for Blender 5.2 compatibility, v1.5.1 is highly recommended. It includes important optimizations and bug fixes specifically leveraging Blender 5.2 LTS exclusive features, along with code refactoring for improved performance and maintainability.

✨Added

  • BTracer: Updated default material to include useful custom attributes ready for use.

🐛Fixed

  • Effector Random & Noise Texture: Fixed Random Seed parameter behavior in Noise modes.
  • Effector Random & Noise Texture: Fixed UV Mapping for Noise Textures.

⚡Changed

  • Blender 5.2 Compatibility: Code refactored for full compatibility with Blender 5.2 LTS. Reduced codebase size to improve performance and ease future modifications.
  • Naming Cohesion: Standardized parameter naming across tools for better consistency:
    • BTracer To Mesh: Material socket renamed to Custom Material.
    • Mapping ColorToInstances: Material socket for Fix Texture renamed to FixTex Material.
    • BTracer: Parameter Trace Collection renamed to Collection.
    • BFracture: Parameter BFracture Collection renamed to Collection.
📦 v1.5.0 — June 26, 2026
▼
⚠️
Breaking Change:

B4D Tools 1.5.0 is NOT COMPATIBLE with previous versions. Significant changes to BCloner distributions and Effector Min/Max parameters have introduced structural modifications that do not function correctly with old setups. Please update all assets.

New Tools & Features

✨Added

  • Advanced Distributions: New "Add Advanced Distribution" option in the BCloner Panel. Includes six pre-configured arrays (2D Grid, Cannonball, Smart Hex, Spline Bed, Stack) and one empty slot for custom distributions. All include bounding box calculation for easier instance setup.
  • Vertex Weight Field: New B4D Field Set that uses Vertex Weights from any Custom Object as a Field, enabling Dynamic Paint integration and Heightmap compatibility.
  • BMograph Animator: New Object tool featuring a Vibrate function (similar to C4D) with Ping-Pong and Repeat animation options. Compatible with single objects, BCloners, and instances.
  • Camera Tools: New object tools including Frustum Culling (hide instances outside active camera view, with margin adjustment) and Level of Detail (use lighter assets for distant instances).
  • Images as MatSlots: New button to bulk-import images/videos from a folder, automatically creating pre-configured material slots with UV and Shader node groups for each file. Supports automatic Multishader modifier addition and video configuration settings.
  • Override MultiShader: New tool to override Multishader MatSlots from any BCloner, allowing multiple texture variants from a single animated BCloner. Includes Transformation Menu (Original/Relative Origin) and Advanced Options (As Instances enabled by default).
  • Automatic Detection: When adding tools, extra selected objects are automatically assigned to relevant parameters (e.g., Custom Mesh, Spline, Target, Volume, etc.) to speed up setup.
  • Asset Type Parameter: Replaces "Use Collection" in BCloners, Matrix ToInstances, BTracer, and BEmitter. Offers three options: Self (original mesh), Object (single custom object), and Collection.
  • Linear Mode: Added Min/Max Origin Pos parameter to adjust the start position of linear clones.
  • Radial Mode: Added Scale X and Y parameters to deform the radial shape into ovals or custom geometries.
  • Stack Distribution: Added Random XYZ on Direction Mode for finer control over clone size randomization.
  • Effector Step: Added Spline Nodegroup with a Float Curve to control step interpolation (editable via Geometry Nodes editor).
  • Effector Delay: Added Stiffness and Damping parameters for String mode (available in Advanced options). Supports Even or String modes.
  • Effector/Field Random & Noise Tex & Formula: Added Loop Animation, Frame Loop Out, and Animation Speed (now percentage-based). Added Noise Seed (when Auto Animation is off). Added Round Falloff option for Field Random.
  • Effector Formula: Added Sine Axis menu to select the animation axis.
  • MultiShader: Added Keep Mesh (Not Instances) parameter and Island Index option for Split To Instances.
  • Mapping Color: Added "Fix Texture" mode (similar to C4D) to project and fix textures on clones.
  • BTracer: Added Split To Instances and Split To Instances Selection parameters.
  • BMoGraph Selection: Added selection of even indices of clones.

🚀Improved

  • UI Refactor: Complete UI refactoring for cleaner code, reusability, and easier future updates. Panel order is now customizable.
  • Documentation: New text-based website documentation accessible via addon preferences. Features dark/light mode, search functionality, and an "Initial Guide" for hierarchy and modifier stack best practices.
  • Viewport Feedback: When a Collection is selected but empty, wireframe cubes are displayed to indicate asset placement areas.
  • Sound Controls: Effector Sound and Field Sound buttons now have two states: Bake Sound to Empty and Restore Blender Layout, preventing unwanted layout changes.
  • Error Handling: Improved error messages when attempting to add tools to incompatible objects, listing compatible object types.
  • Advanced Distributions: Container objects for Advanced Distributions are hidden in viewport and render by default. Rotation and Scale transformations now correctly propagate to distribution clones.
  • MultiShader Performance: Improved performance by preventing unnecessary geometry duplication.
  • Effector Min/Max: Refactored Min/Max parameters for all Effectors (Plain, Random, Step, Image Text, Noise Tex, Sound, Volume, Time, Formula). Default scale values changed from 1 to 0 for correct functionality.

🐛Fixed

  • BCloner Object Mode: Fixed Align parameter to use face normals by default in Surface and Volume modes. Fixed "Use Collection" logic (now "Asset Type") to handle single objects correctly.
  • BCloner Grid/Linear/Radial/Honeycomb: Fixed display of ID Asset and Random Seed parameters.
  • Advanced Projected 2D Distribution: Fixed Align To Normal and Self Transformation behaviors.
  • Advanced Spline Bed Distribution: Fixed Scale Rail parameter.
  • Effector Volume: Fixed Volume Selection.
  • Effector Noise Tex: Fixed UV Map for noise.
  • Effector Random: Fixed Scale parameter compatibility with Field tools.
  • Effector Transform: Fixed Use Material Fixed and Material Selection behaviors.
  • Selection: Fixed Selection option for Object Tools to work as expected.
  • BMoGraph Selection: Fixed Display Index to prevent duplication of original instances.
  • Dynamic Paint: Fixed compatibility issues with Heightmaps.

⚡Changed

  • Naming Conventions: Standardized panel and parameter names for cohesion (e.g., "Advanced Parameters," "Separated Assets," "Reset Coordinates").
  • BTracer Icon: Changed icon to distinguish it from Animator Tools.
  • Clones from Distribution: Converted to a button switch for better parameter visibility and UI cleanliness.
  • Mapping Color: Replaced Boolean switches with a "Mode" menu for clearer selection (ColorToVertex, ColorToInstances, Fix Texture).
  • Effector/Field Animation: Animation Speed is now a percentage parameter (default 100%). Loop Animation is now a toggleable parameter.
  • Effector Formula/Field Formula: Renamed "Wave/Voronoid Texture Configuration" to "Wave/Voronoi Type" for compactness.
